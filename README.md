# CCSA109: Application Control and URL Filtering

##  Assignment Overview
This repository contains my theoretical assessment for CCSA109 – Application Control and URL Filtering, part of the Check Point Certified Security Administrator (CCSA) training programme.

## Topics Covered
- Application Control and URL Filtering fundamentals
- Application identification using Deep Packet Inspection (DPI)
- URL categorization and custom URL categories
- Access Control Policy integration
- Application and website access management
- Integration with Identity Awareness, HTTPS Inspection and Threat Prevention
- Application Control and URL Filtering deployment workflow
- Configuring rules for monitoring, blocking and limiting application traffic

## Repository Contents
- Theoretical assessment questions and answers.
- Application Control and URL Filtering configuration scenarios.
- Deployment workflow and SmartConsole navigation steps.

## Objective
To demonstrate an understanding of how Check Point Application Control and URL Filtering identify, monitor and control network applications and website access, and how they integrate with Access Control policies to improve network security.
