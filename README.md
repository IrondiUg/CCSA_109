# CCSA107: Identity Awareness

##  Assignment Overview
This repository contains my theoretical assessment for **CCSA107 – Identity Awareness**, part of the Check Point Certified Security Administrator (CCSA) training programme.

## Topics Covered
- Identity Awareness fundamentals
- User and computer identification
- Identity Sources and authentication
- Access control based on user identity
- Identity Awareness integration with security policies

## Repository Contents
- Assessment questions and answers.

## Objective
To demonstrate an understanding of how Check Point Identity Awareness identifies users and computers and uses identity information to enforce access control policies.
